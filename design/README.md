# 轻羽 FeatherPad · 设计交付

本目录交付桌面编辑器的 UI 方案与离线交互原型。它不是产品实现，**不会读取、写入或监听系统文件**。正式工程根目录约定为 `E:\Codeing\ai-workspace\featherpad`；目录重命名不影响本目录中的相对资源引用。

## 打开

直接双击 [prototype.html](./prototype.html)，使用本机 Edge / Chrome 等现代浏览器打开。无需服务器、构建、安装依赖或联网；请将 [tokens.css](./tokens.css) 与它放在同一目录。JavaScript 和 SVG 图标都在 HTML 内，字体使用系统本地后备。

正式产品的 Markdown **默认源码模式**。原型为了展示阅读体验，首次打开默认**源码 + 阅读分屏**；可以在右上角切为源码或阅读。配置样例使用正式的 `source` 默认值，不会因为原型展示状态而改变产品约定。

最低有效视口为 **800 × 560 CSS px**。建议 1280 × 800 或以上。小于 1100 宽时，侧栏改为覆盖层；这不是手机产品，没有 320px 手机布局。Windows 125% / 150% / 200% 缩放规则和物理分辨率换算见 [UI-DESIGN.md](./UI-DESIGN.md)。

## 支持的交互

- 目录折叠、打开 Markdown / JSON / Java / SQL；单击预览、双击固定，编辑后自动固定。
- 多标签切换、关闭、dirty 圆点；未保存关闭时选择取消 / 放弃 / 演示保存并关闭。
- 原生 textarea 真实输入，行号与行列更新；Tab 插入空格，Shift+Tab 离开编辑区。
- Markdown 源码 / 阅读 / 分屏切换；标题、段落、引用、列表、表格、粗体、行内代码和 fenced code 的安全 DOM 预览。
- 左侧全文搜索内存中的所有样例，点击结果定位选区；快速打开文件名过滤。
- Ctrl+P 快速打开、Ctrl+Shift+P 命令面板，方向键选择、Enter 执行、Esc 关闭。
- 设置对话框的外观 / 编辑器 / Markdown / 文件与安全 / 快捷键分类；亮暗主题、密度、字号、换行与同步滚动即时生效。
- 侧栏开关、侧栏宽度拖动、源码与预览比例拖动；分隔条聚焦后可用左右方向键调整。
- 外部变更冲突横幅演示，保留演示稿或载入内置样例版本；有修改时再次确认。
- 欢迎页、新建无标题文档、无搜索结果、合理 toast 和帮助中的交互支持清单。
- PDF 导出设置设计：文件名、纸张与页边距可调整；生成按钮明确禁用且标注“未接入”。正式版必须真正生成可打开的 PDF 文件，不能以打印对话框代替。

## 明确未实现

文件 / 文件夹选择、系统文件拖入、磁盘保存、编码转换、原生窗口控制、文件监听、差异比较、标签拖拽重排、多编辑器组、会话恢复、代码执行、数据库连接与真正 PDF 生成均未实现。有关入口会显示说明或处于明确禁用状态，不呈现假成功。

按 **Ctrl+S** 只将当前内存内容记为演示“已保存”基线，并提示**未写磁盘**。刷新、关闭浏览器或重开页面会重置全部编辑与设置；原型没有 localStorage。不要把唯一副本的文字放在原型中。

Markdown 输入通过白名单 DOM 节点与 textContent / Text 生成，不使用用户输入拼接 HTML。HTML、脚本、图片和 URL 不执行也不发出请求。不支持完整 CommonMark，不提供语法高亮、多光标和精确源行同步。自动换行时隐藏非精确行号，同步滚动按比例演示。

## 5 分钟检查路线

1. 双击打开 [prototype.html](./prototype.html)。确认“轻羽 FEATHERPAD”与羽毛标记、默认分屏、设计演示标识和“未写磁盘”状态。切到 `config.json`、Java、SQL，再回到中文 Markdown。
2. 单击未打开文件，看到斜体预览标签；双击固定。在源码输入一行文字，确认 dirty 圆点；关闭标签，试取消、放弃修改，再试演示保存。
3. 在 Markdown 输入 `<img src=x onerror=alert(1)>` 或 `<script>alert(1)</script>`，确认预览显示纯文本，没有弹窗或图片请求。切换源码 / 阅读 / 分屏。
4. 在搜索侧栏输入“theme”，点击结果定位。Ctrl+P 搜索 `java` 并 Enter；Ctrl+Shift+P 搜索“主题”并执行。浏览器若保留某快捷键，使用同名菜单或按钮。
5. 打开设置，切换深色 / 紧凑 / 16px。用 Tab / Shift+Tab 确认焦点留在模态，Esc 关闭并回到触发位置。尝试侧栏和分栏拖动，再用键盘调整。
6. 在更多菜单演示外部变更；尝试保留与载入，确认不假装真实磁盘内容。文件菜单打开 PDF 导出设计，确认生成按钮明确未接入。
7. 关闭全部标签进入欢迎，点击新建文本。缩小到 1024 和 800 宽，检查覆盖侧栏、遮罩、Esc 和选择文件后收起。高度不低于 560。
