# 恢复未保存内容

轻羽会为未保存正文写入本地恢复副本。停止输入后约1秒调度，持续输入最长约5秒调度一次；只有已经成功持久化并校验的副本受保障。强杀、断电或存储故障可能丢失最后尚未写入的输入。

正常关闭窗口时，轻羽等待所有未保存文档的最新副本及会话清单写入成功。重启恢复正文、原有编码和换行意图、标签及编辑位置，不恢复完整undo历史。M1当前实现单窗口/单组，双分栏与多窗口由后续功能扩展。

如果无法安全退出，窗口会保持打开，可以重试、返回编辑、全部另存或明确放弃。另存失败或取消时正文仍保留。“放弃全部修改并退出”会标记当前版本不再自动恢复；如果放弃或关闭结果不明确，应用保留正文，并为后续保护使用新的恢复版本。

命名文件在关闭期间被外部修改时，轻羽保留磁盘原件，并以只读方式打开恢复正文。核对后另存到新文件，不直接覆盖外部修改。找不到的文件或目录显示会话占位，可重新选择或移除占位；移除占位不删除源文件或恢复正文。

保存事务未确认完成时，恢复候选面板允许“打开恢复副本”。副本使用新的文档身份，保存需要另选路径；原件、待保存字节和旧备份继续保留。副本只有在新的恢复快照成功后才显示已保护；如果保护失败，请优先另存。

每文档最多保留最近10份已校验冗余。超过30天的记录仅提示核对，唯一未保存副本不会因过期自动删除。恢复与保存事务共享256MiB预算，空间不足会拒绝新写入并提示；不要把“有旧副本”当成最新输入已经安全保存。

默认本地记录位于Windows本地应用数据目录的`app.featherpad.desktop`下，正文与清单在`recovery`，保存事务在`save-transactions`，会话和授权元数据在`session`。这些记录可能包含敏感正文，请勿随意分享整个目录。损坏副本会被隔离于自动恢复流程，原始文件保留供人工核对。完整隐私管理和便携数据目录仍由后续阶段实现。
