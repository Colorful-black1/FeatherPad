# 轻羽 FeatherPad 使用指南

当前为0.1.0内部候选版。M0–M4已通过阶段验收；目标机（Windows10、4核/8GB）的性能与兼容验收未进行，尚不称完整v1。已验证环境为Windows11 x64 / WebView2 156.0.4314.58。

## 安装或便携运行

安装包安装到当前用户目录；覆盖升级保留设置和恢复数据，普通卸载也保留应用数据。便携包先完整解压到可写目录，再运行`featherpad.exe`；保留同目录的`portable.flag`，数据写入旁边的`data/`。移动便携版时连同该目录一起移动。只读介质、无效marker或链接形式的data目录会明确拒绝启动。

需要已有Microsoft Edge WebView2 Evergreen Runtime。程序和安装器不会自动联网下载Runtime；缺失时显示安装指引。候选包未签名，没有已验证发布者；可用随包SHA256SUMS核对文件。

## 打开与编辑

`Ctrl+N`新建，`Ctrl+O`打开文件；侧栏可添加多个文件夹、收藏目录和打开最近记录。快速打开用`Ctrl+P`，命令面板用`Ctrl+Shift+P`；设置中能查看和调整快捷键。状态栏显示编码、换行、语言、行列及未保存状态。选择语言模式可覆盖自动检测；选择自动检测会移除覆盖。

单击文件树可使用预览标签；编辑后保留为普通标签，可固定、重排、移动到第二编辑组。双分栏共享同一正文与undo；第二窗口打开已有写所有者的文件时显示只读镜像，不能绕过保存保护。

重启恢复文件或切换标签时，属于已授权工作区的当前文件会在左侧自动展开目录、选中并滚动到可见位置，不抢走编辑器焦点。独立打开且不属于工作区授权的文件不会自动添加文件夹。

支持多光标、矩形选择、折叠、括号跳转、行操作、导航历史和文本缩放。主题、字体、换行显示等在设置中调整。仅有高亮和文本操作，不运行文档、代码、SQL或项目配置。

## 保存、编码与外部变化

`Ctrl+S`保存当前文件，无标题文件先选目标；另存为改变当前绑定，保存副本保留当前绑定。保存串行核对磁盘版本，旧回执不会清除后来输入的未保存标记。取消或失败时原文及缓冲继续保留；错误未解除前不要把磁盘文件当作已保存成功。

成功保存后正常保留的事务记录不会在每次启动时告警。若存在未完成事务、临时文件/备份残留、明确的清理失败或损坏证据，仍会提示；本次优化不删除这些记录，也不改写源文件。

编码识别不确定时需显式选择，不能表达的字符会阻止有损转换。换行转换与逐行混合换行可预览和撤销；只读分块、限量试开和图片不是完整可保存文本。大文件按只读/限量策略处理，不能把片段另存为假完整文件。

磁盘出现变化时，未修改缓冲可自动重载并提示；有未保存内容则保留缓冲并显示冲突。可比较磁盘、保留当前内容另存，或明确确认重新载入/覆盖。重新载入先保护草稿；确认后磁盘又变化会拒绝旧确认。硬链接保存需要额外确认只替换当前路径，其他别名保留原内容。

## 搜索与工具

文件内查找/替换用`Ctrl+F`/`Ctrl+H`，目录搜索用`Ctrl+Shift+F`。目录搜索显示实际范围、增量结果、跳过和取消状态；取消结果会标为不完整。默认不跟随目录链接，并应用隐藏、忽略和大小预算。正则采用有界兼容子集，不支持的表达式会提示。

跨文件替换先预览，再二次确认；未保存缓冲、只读和变化文件排除或标冲突。提交前写恢复记录，提交后能对符合当前版本的文件回滚。文件有后续修改时不会为回滚覆盖新内容；批次可能部分完成，应核对逐项结果。

格式化和文本转换先检查范围、预览变化，再一次应用，可一次undo。JSON/JSONC、XML、HTML/CSS/JS/TS、SQL和YAML使用离线解析；SQL需选择适当方言，无法保真会拒绝。Java格式化不提供。两文件比较只读，不会把差异自动写回。

## Markdown、图片与导出

Markdown有源码、阅读、分屏三种模式，共享正文和undo。目录、任务勾选和同步滚动绑定当前快照；旧预览不能改写新版本。实时预览有大小/时间限制，超限可手动生成或返回源码。

默认不启用原始HTML；开启后仍执行结构白名单清洗。Markdown/HTML/SVG预览隔离脚本、远端资源和Tauri权限。相对图片需要文件或显式资源目录授权；远端图片保持阻止，外部链接需明确确认。PNG/JPEG/GIF/WebP/SVG提供只读查看与缩放，GIF可暂停；SVG源码重开是显式文本操作。

导出可生成离线HTML或实际PDF，支持相应页面选项。导出读取冻结快照并核对版本，取消/失败保留源正文和原目标；资源无法加载时会说明。PDF导出不是系统打印对话框的替代截图。

## 桌面集成与隐私

命令行例子（路径含空格时加引号）：

```powershell
featherpad.exe "笔记.md"
featherpad.exe --new-window "笔记.md"
featherpad.exe --goto "笔记.md:12:3"
featherpad.exe --reuse-window --wait "笔记.md"
featherpad.exe --help
```

`--wait`等待本次文档关闭或明确放弃；仅保存不会立即结束等待。参数不合法返回非零退出码。多个路径可同时打开，用`--`结束选项解析。

全局唤起、打开方式候选和Explorer右键菜单默认关闭，在设置中显式启用。不会改写UserChoice或抢占默认应用；第三方改写的注册项不会强行撤销。

安装版数据位于`%LOCALAPPDATA%\app.featherpad.desktop`；便携版位于`data/`。最近、收藏、会话授权、恢复正文和保存/替换事务可能包含敏感路径或内容。隐私管理可以分别清理历史和安全冗余，活动未保存的唯一恢复副本受保护；关闭历史只停止新记录，已有项需显式移除/清空。不将这些数据或正文发送到服务器。

未保存内容保护、损坏清单及恢复方式见随包[恢复指南](RECOVERY.md)。正常退出会等待落盘；强杀/断电不能承诺最后输入零丢失。
