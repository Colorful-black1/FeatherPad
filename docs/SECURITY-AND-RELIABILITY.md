# 安全、文件可靠性与本地隐私

状态：v1 必须实现的约束，尚未进行产品安全测试。关联：[接口契约](CONTRACTS.md)、[测试验收](QUALITY-GATES.md)、[实现计划](../tasks/plan.md)。

## 1. 资产与信任边界

核心资产是用户源文件、未保存内容、文件路径/最近记录，以及用户允许应用访问的目录。应用无账号、无服务器、无云同步、无内置AI调用；不会为检查更新或渲染预览自动上传用户内容。AI协助开发不意味着产品内有AI功能。

| 边界 | 常见滥用 | 必须控制 |
|---|---|---|
| 磁盘文本 → 编辑/预览 | 脚本HTML、超长单行、递归结构耗尽资源 | 纯文本编辑；预览禁脚本/远端加载；尺寸和时间预算 |
| Markdown链接 → 本地资源 | `../`、编码绕过、junction跨出目录读取敏感文件 | 后端 canonicalize 后检查 grant；不将任意路径暴露给 asset URL |
| Web UI → Rust | 伪造任意路径、删除/执行命令 | opaque grants、参数schema、最小Tauri capability，禁任意shell |
| 用户文件 → 保存 | 竞态覆盖、编码损坏、写盘中断 | revision检查、串行save、安全替换、恢复快照、错误可见 |
| 目录 → 扫描 | junction循环、巨量文件、权限错误 | 默认不跟随reparse point、有界遍历、取消、逐项错误 |
| 依赖 → 开发/发行 | 恶意install script、包名拼错 | 锁文件、精确脚本allowlist、审查来源、审计 |
| AppData → 启动恢复 | 损坏清单/大快照/旧版本schema | 大小限制、schema校验、迁移备份、逐条隔离 |

## 2. 预览隔离

- Markdown 默认禁 raw HTML；即使启用有限 HTML，也只使用明确允许标签与属性，并经 DOMPurify 最终清洗。
- 不允许 script、iframe、object、embed、表单提交、on* 属性、javascript/vbscript URL、可执行SVG。SVG只做隔离的图像解码/安全展示，不内联其DOM。
- 远程图片在v1预览/导出中始终阻止网络请求，显示“远程图片已阻止”；用户可显式在系统浏览器查看原URL，应用不抓取/缓存。不要让追踪图片绕过“无遥测”。本地图片可在已授权工作区中解析；越界资源需明确新授权。
- HTML 文件第一版提供源码编辑与安全静态预览（F-EDIT-020 / T310）；静态预览禁止执行脚本、禁止表单、禁任意网络、禁访问应用 IPC。它不是网页运行环境。
- 生产 CSP 明确配置 default/script/style/img/connect 等来源，只放行实际必需的 Tauri IPC 与受限资源协议；不因预览失效删除 CSP。开发服务器仅 loopback 并隔离生产配置。
- HTML 导出为清洗后的独立离线文件：文档、受控样式和允许的本地图片内嵌，单资源≤20MiB、总嵌入≤50MiB；缺失/越权/超限列出后选择“带占位继续/取消”，不静默改为附属资源目录。PDF由同一隔离文档真实生成，禁止渲染期间主动联网。

## 3. 文件系统约束

- 所有写入、重命名、回收站删除都必须由用户动作或明确启用的自动保存触发。打开文件夹不得创建项目文件、索引数据库或格式配置。
- 目录授权不自动授权它的 junction 目标；路径字符、相对段、大小写、Windows保留名、符号链接及UNC路径逐项处理。网络盘超时和不可用不能阻塞UI。
- 删除默认回收站；失败不静默永久删除。不把递归删除任意路径作为后端通用IPC。
- 原文件安全替换必须在Windows实测：源文件锁、杀进程、磁盘满、权限失败、重命名失败。原子替换不对断电提供绝对保障；未经实测不宣称保留所有ACL/ADS/时间戳。若发现不能安全保留文件元数据，提示并给明确策略。
- 文档打开若无法可靠识别编码，提示选择；有损解码只读或明确授权后另存。保存前编码不可表示时阻止，建议UTF-8另存，不默认写问号替代字符。
- 大文件按 [产品方案](PRODUCT.md) 的精确阈值处理；二进制文件不进可编辑文本区。图片按内容类型解码，不能只相信扩展名。

## 4. 恢复保障的真实范围

快照debounce1秒，持续输入最长5秒刷新一次；退出前尝试flush，失败保留窗口并显示选择。已确认写入的恢复版本可恢复；强杀、断电、磁盘故障可能丢失最后一次快照之后的输入，不能承诺绝不丢字。源文件已保存与快照已保存要有不同的状态语义。

未保存草稿不得被普通缓存清理程序删除。恢复默认在本机当前用户目录，使用继承的当前用户访问权限；不是加密保险箱，不声称可抵抗同一用户权限下的恶意程序。提供清除最近记录、清理恢复副本和定位数据目录的入口，并对删除未恢复内容再次确认。

跨文件替换必须预览、确认、逐文件冲突检查、写前备份、结果列表与恢复入口；部分失败保留已完成项的证据和恢复能力。不以“事务”命名一个实际上不能跨文件原子提交的操作。

## 5. 默认网络与系统集成

v1不提供自动遥测、云功能或自动下载更新。可以显示本地版本与手动打开发布页；外链需要用户动作。Windows文件关联/右键菜单/CLI安装显式opt-in，可撤销；不申请管理员权限作为常规运行前提。

安装器不能为缺WebView2而静默下载系统组件；给离线依赖说明或引导用户选择已有可用运行时。开发环境的新安装目录遵守 [本机环境约束](ENVIRONMENT.md)，产品用户安装目录由安装器显式选择，默认推荐 E 盘，不擅自替用户写注册表。

## 6. 发布依赖检查

M0确定唯一pnpm版本和lockfile，首次安装禁脚本，逐包审查必要构建脚本并记录。Rust Cargo.lock同样提交；不允许构建过程按branch漂移拉依赖。发布前运行 `pnpm audit`；Rust审计工具若本机没有，先查再按E盘安装约束决定安装，不把未运行写成已通过。审计结果按runtime/build/test可达性与修复风险记录，禁止自动强制升级。

对用户正文、绝对路径、恢复内容不打日志。崩溃报告如未来增加，必须重新设计用户知情、脱敏和导出流程，不能沿用当前“无上传”定位自动开启。

## 7. 必须有的反例测试

1. Markdown 含 `<script>`、事件属性、`javascript:`、恶意SVG、远程像素图：不执行、不自动联网、不调用IPC。
2. 相对图片 `../../secret`、URL编码绕过、junction逃逸、未知grant：拒绝访问。
3. 超长单行、多层嵌套Markdown/JSON、灾难性正则：可取消/降级，无UI长期冻结。
4. 保存过程中磁盘被外部改动、保存响应迟到、重复保存requestId：冲突可见且新输入仍dirty。
5. 写盘阶段故障注入与强杀：原件或已确认快照可恢复，临时文件可识别清理。
6. 跨文件替换一半失败、回滚前又改文件：报告部分完成，不覆盖回滚后的新工作。
7. 伪造会话清单或新版schema：逐条隔离、备份，不让启动崩溃循环。
