> 本表共 **86** 个稳定 ID；完整 v1 包含 M0–M5。阶段表示首次达到验收，不代表后续阶段免于回归；未被阶段验收索引覆盖的 ID 仍为**待实现 / 待验证**。未单列的操作须归入相应 ID，不得通过正文增加不可追踪范围。

- **G0 已通过（2026-11-01）**：F-DESK-013，证据见 [M0验收](acceptance/M0.md)。
- **G1 已通过（2026-11-03）**：F-FILE-001..005、008..011、013..015、017..018；F-WORK-001、003..005、007；F-EDIT-001..003、008、012..013、017..018；F-SEARCH-001..003；F-DESK-001..002、010..011，共34项。证据、真实/mock边界和最终Release见 [M1验收](acceptance/M1.md)。

## 验收索引

每行验收结合所属规格中的 error-state 和 test strategy 执行。验收记录应存 feature ID、版本、平台、夹具、预期/实际、证据路径；未搭建的测试脚本不能标通过。功能矩阵不承诺 100% 代码覆盖率；数据丢失、安全和回滚路径必须有自动化加手工故障演练。

依赖索引见 [能力映射](../CAPABILITY-MAP.md)，全局阈值和不包含范围见 [PRODUCT](PRODUCT.md)。任一规格新增可观察能力须先分配或明确归入已有 ID。小地图允许不实现，其可选性不能扩展到矩阵其余必需能力。
