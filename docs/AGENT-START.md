# Agent 启动与持续迭代提示

使用方法：在agent编辑器中**单独打开 `E:\Codeing\ai-workspace\featherpad`**，将下面相应提示交给agent。项目规则入口是 [AGENTS](../AGENTS.md)。不要把父目录多个项目一并交给agent。

## 1. 从零开始完整实现（可直接复制）

```text
请实现本工作区的「轻羽 FeatherPad」桌面编辑器。

先读 AGENTS.md、README.md、tasks/PROGRESS.md、tasks/plan.md 和 tasks/todo.md；按当前任务只读相关功能矩阵、模块SPEC、技术与UI文档。

目标是完成M0–M5的完整v1，包括全部86项必需功能；M1只是MVP，关卡通过后继续。请执行实际实现，不止输出计划。每轮选一个依赖满足的小任务，完成真实UI→bridge→本地服务闭环；小切片只跑受影响模块的定向检查和行为测试，修复失败并简记证据，再推进下一任务。

环境先复查E:\Codeing和默认目录，优先复用已有工具；本项目会话使用已有Node22.13.0、pnpm10.32.1、Rust/MSVC。所有新增工具、SDK、安装包和缓存只能放E:\Codeing下，不要改全局nvm/PATH，不要为了方便重新安装已有环境。

UI参考design/prototype.html和UI-DESIGN，但原型只是演示，不要把textarea和演示保存当作成品。产品必须使用CodeMirror6和Tauri2，真实打开目录、保存、恢复、搜索与导出。

遇到失败先定位原因并修复。不要删除测试、造空脚本、调高性能门槛、把Web mock当原生验证、把弹打印框当PDF导出。正常实现和可逆修复无需反复请求确认；若真正缺少授权、安装无法遵守目录要求或缺少外部凭据，记录具体阻塞和已尝试路径。

按docs/QUALITY-GATES.md执行分层验收：普通T任务完成时验证完整功能流程，相邻普通T可合并一次Release验收；保存、删除、恢复、编码转换、跨文件替换等高风险T任务必须做相关真实Release验收；M阶段统一整体回归。同一代码/构建的有效证据直接复用；大文件、100k目录、满盘、强杀和性能只做专项检查，不随普通UI修改重复执行。小切片只简记，完整T任务汇总功能ID、改动文件、命令/exit code、mock/原生范围、证据和下一步，M阶段出整体报告。未验部分明确标待验，不删除测试、不降低断言或性能门槛，不把待验标通过；现有测试产物不自动删除，只维护清理清单。新会话按记录续做，不重新搭工程。

最终交付实际可运行安装包和便携包、sha256、用户指南、恢复说明、完整逐项验收和已知限制。不要自动公开上传、发布或购买签名证书。没有证据不要宣称完整完成。
```

## 2. 持续 loop 的目标文本

不同agent对 `/loop` 的语法、频率与退出条件支持不同。本仓库不假设某个不存在的loop插件，也不提供一个冒充可执行命令的斜杠语法。若你的工具已提供loop，将以下文本设为循环任务，并使用该工具本身的停止/预算机制：

```text
持续推进轻羽 FeatherPad：读取AGENTS和tasks/PROGRESS，从tasks/todo挑依赖满足的首个未完成任务；实现、定向验证、修复并简记，再继续。每轮实际推进一个切片或处理一个明确失败。小切片只跑受影响检查；普通T完成时验完整流程并可按相邻任务合并Release，保存/删除/恢复/编码转换/跨文件替换等高风险T完成时必须做相关真实Release验收；M阶段统一整体回归。有效证据按同一代码/构建复用，大文件、100k目录、满盘、强杀和性能只按专项执行；未验保持待验，不删除测试、不降门槛、不把待验标通过，历史测试产物只列清理清单。阶段关卡通过后自动进入下一阶段，不能停在MVP。只有M0–M5及86项必需功能均有真实验收证据和可运行产物，才输出完成。当前轮无法继续时保留具体错误、尝试、恢复状态与下一步，不循环重复同一失败命令。禁止虚构验证、越界安装或自动公开发布。
```

循环预算由使用的agent系统控制；任务复杂时可连续多轮和换会话，不能承诺固定迭代次数内必然完成。

## 3. 中断后继续

```text
继续本项目，不重建工程。先读AGENTS.md和tasks/PROGRESS.md，核对todo状态与实际文件；若上轮留下进行中任务，先复现其最后失败并完成验证。只加载当前模块SPEC与相关代码。保留已有用户改动，按M0–M5继续到完整v1。
```

## 4. 仅实现MVP时的独立提示（主动缩小目标才用）

```text
本轮只完成M0和M1，按项目规格达到G1并交付可试用桌面包。不要标记完整v1完成；保留M2–M5未完成任务，记录下一步，后续再继续。
```

## 5. 交接最小信息

每次换会话，带上当前阶段/任务ID、最新构建路径、最后失败命令、最近一次通过证据、未提交改动、下一任务。不需要把所有规格全文塞进提示；先读进度再按模块加载。
