# 轻羽 FeatherPad 0.1.0 内部候选说明

2026-11-04，开发分支`codex/featherpad-v1`。候选状态：M0–M4阶段关卡已通过，内部候选版可用。版本号仍为0.1.0；目标机兼容与性能未实测，不是已声明支持全部环境的正式v1。

## 已提供

- 真实Windows文件读写、编码/换行、保存冲突、回收站、恢复与热退出。
- 多根目录、收藏/最近、标签/分栏、多光标/导航、全文搜索及有预览/回滚的跨文件替换。
- Markdown三模式与安全资源、离线HTML/PDF、格式化、文本工具、图片/HTML与只读diff。
- CLI、单实例/多窗口、用户级安装/升级/卸载、便携、选择加入的系统集成。
- 发布前补充首批增量搜索、按需视图加载和预览性能优化；开发机性能观测与失败记录见`tasks/PROGRESS.md`。

## 当前边界

- Win10、4核/8GB和最低支持WebView2尚未实测，当前仅Win11开发机结果；不承诺已满足这些目标环境。
- 目标机性能与兼容矩阵未实测，未签名，无自动更新/下载Runtime/在线账户。
- 恢复仅保护已成功落盘副本，强杀和断电可能丢失最后未落盘输入。批量替换不是跨任意外部进程的全局事务。
- 限量/大文件片段不能保存成假完整文件；未知编码、有损转换、过期版本和无法保真的格式化会拒绝。
- 远端资源默认阻止；完整IDE能力、终端/LSP/插件市场/云服务/AI聊天不在范围内。可选小地图未提供，Java格式化不提供。

使用见`USER-GUIDE.md`；恢复见`RECOVERY.md`；第三方原始通知见`THIRD-PARTY-NOTICES.md`和`LICENSE-TEXTS.txt`，MPL-only依赖及修改的Wry源码见随内部交付的`THIRD-PARTY-SOURCES.zip`。包与哈希需以实际生成的SHA256SUMS为准，本文不预填未生成的构建结果。
