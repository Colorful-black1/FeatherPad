# 轻羽 FeatherPad 产品定义

> 文档方案，待实现、待验证。用户授权本次完整文档交付，未声称用户已批准方案。当前交付范围包含 M0–M4；M1 只是可用 MVP。项目名暂未进行商标检索。

## 产品目标

轻羽 FeatherPad 是面向 Windows 10/11 x64 的免费、离线、本地文件编辑器。主要用户是快速查看和修改文本、代码、配置、日志、Markdown 的个人用户与开发者。常用操作能用键盘和少量点击完成；文本安全和可恢复性优先于炫技。技术基线是 Tauri 2、React、TypeScript、CodeMirror 6、Rust，不在本阶段安装工具、创建产品代码或宣称命令已可运行。

成功意味着用户能放心完成“打开文件或文件夹 → 找到内容 → 编辑/替换/格式化 → 对比冲突 → 保存或导出 → 关闭与恢复”的完整闭环。完整性由 [86 项功能矩阵](FEATURE-MATRIX.md) 定义，每项都有模块、阶段和可验证验收。布局与视觉细节由项目 UI 文档补充，不改变业务依赖。

## 完整 v1 范围

- 文件：新建、打开、多文件打开、另存为、全部保存、最近、收藏、单根/多根工作区、资源树、新建/重命名、回收站删除、拖放。预览标签、固定标签、拖排、关闭其他、重开、双分栏。
- 编辑：选中/撤销/重做、缩进/注释、多光标/列选择、移动复制行、括号匹配、基础文本和括号补全、空白显示、折叠、字号、换行；可选小地图提供设置开关，不是 v1 必须实现的可视化组件。
- 查找工具：文件内/目录全文搜索、正则/大小写/整词/排除/取消；跨文件替换预览、二次确认、冲突检查和回滚记录；两文件和磁盘冲突 diff；明确语言边界的格式化、文本转换。
- Markdown：source/read/split 三模式，GFM 表格、任务列表、代码高亮、相对图片、目录大纲、链接、安全 HTML；HTML 与 PDF 本地导出均是完整 v1 必需项。
- 可靠性：编码与换行选择、外部变更、只读、磁盘满、未命名草稿、崩溃恢复、可选自动保存、热退出；大文件和二进制安全处理。
- 桌面：主题、字体、Tab/全局快捷键、最近记录隐私、轻量图片查看、安装/便携、单实例路由和多窗口、CLI、显式选择加入的 Windows 关联/右键菜单。

不包含运行/调试器、数据库、内置终端、插件市场、账号、云同步、AI 聊天、LSP 或语义补全。Java 仅高亮，不能以“支持 Java”暗示语义格式化。后续 AI 可依据文档独立开发，但 AI 能力不是产品依赖。

## 核心交互约定

首次进入提供新建、打开文件、打开文件夹和最近列表。单击资源文件在现有标签之后打开新的固定标签，不替换已打开文件；右键标签可关闭当前 / 其他 / 右侧 / 全部、复制路径或在文件资源管理器中显示。关闭脏文档提供保存/不保存/取消，另存为取消等于未保存；关闭窗口对所有关联文档作整体决策，可取消整个关闭动作。显式“不保存”须删除对应待恢复草稿，不能下次又悄悄恢复。

编辑缓冲留在前端；每次按键不跨 Rust。CodeMirror 事务管理撤销和选择，Rust 负责磁盘 I/O、枚举/监听、编码和持久化。保存获取特定 `bufferVersion` 的快照，单文件写入队列串行，携带 `expectedRevision`；保存成功仅将已保存版本标为 clean，期间新输入仍 dirty。磁盘 revision 包含文件身份、大小、时间与内容摘要，不仅依赖 mtime。保存前复核、同目录临时文件落盘、替换前再核对；无法对任意第三方进程写入保证完全无竞态，不能宣传任意进程间原子事务。

外部变更时，干净文件自动重载并尽量保留视图位置，显示提示；脏文件保留缓冲，提供磁盘 diff、重新载入、另存为、明确确认覆盖。删除/重命名不让编辑内容消失。回收站不可用时失败并解释，不自动降级永久删除。

## 编码、换行与大文件默认值

| 项目 | v1 契约 |
|---|---|
| 编码 | 支持 UTF-8、UTF-8 BOM、UTF-16LE/BE（含 BOM 识别）、GB18030、GBK、Shift_JIS、Big5、Windows-1252。无 BOM 先严格 UTF-8，失败仅给候选并要求选择，不宣称准确自动识别。新文档默认 UTF-8 无 BOM。 |
| 手动重开 | “以编码重开”会替换缓冲，dirty 时先保存/放弃/取消；解码替换字符或编码不可表示字符先预览位置/数量并二次确认有损，不自动保存。 |
| 换行 | 新文档默认 CRLF，可设置 LF。已有文件默认 preserve，原有 LF/CRLF 混合逐个保留；新插入行用文档主导类型（平手用首个，空文档用默认）。显式统一 LF/CRLF 是一次可撤销编辑，保存前显示目标。孤立 CR 保留并提示。 |
| ≤2 MiB | 正常文本功能。1 MiB = 1,048,576 字节，按磁盘原始字节判断。 |
| >2 MiB 且 <20 MiB | 降级可编辑：关闭小地图、折叠、全文语义式高亮/自动补全/实时 Markdown，使用纯文本视图；按需文件内搜索，格式化与渲染需大小提示并取消支持。极长行同样触发降级。 |
| ≥20 MiB 且 ≤100 MiB | 大文件只读、分块视图/限量结果，禁止编辑/格式化/替换/完整 Markdown；清晰标注只读原因，不偷偷截断后允许保存。 |
| >100 MiB | 拒绝完整打开，可由用户明确选择前 1 MiB 只读预览，标注截断和总大小；不提供保存。 |
| 二进制 | BOM/已选编码解码优先；对原始字节和解码后文本综合检测 NUL/控制符，UTF-16 不因 NUL 误判。未知二进制显示原因/文件信息，可手动尝试文本只读，不能误保存。 |
| 图片 | PNG/JPEG/GIF/WebP/SVG 安全查看；SVG 禁脚本/外链，单独沙箱；默认20 MiB或40百万像素超限须明确拒绝完整解码，禁止压缩炸弹。 |

目录搜索默认跳过 ≥20 MiB 文件、二进制、符号链接目录以及 `.git`、`node_modules`、构建输出；显示跳过统计。2–20 MiB 可流式扫描。单次最多 10,000 个匹配/50 MiB 结果预算，达到上限提示截断，可缩小范围重试。正则取消/超时必须可中断，不能只让按钮变灰。

## 数据保障与隐私

自动保存默认关闭；开启后默认停止输入 1,500 ms 才尝试保存已命名、可写、无冲突文件；无标题草稿不擅自选择路径。恢复快照默认停止输入后 1,000 ms 写一次，持续输入至少每 5 秒调度一次。只有成功持久化的快照受保障；崩溃可能丢失尚未持久化的最后几秒。计划退出的热退出须等待全部 dirty 快照和 manifest 成功落盘，失败则阻止退出并提供重试/另存/明确放弃；不能用“有快照”声称永不丢失。突然断电、设备损坏、杀进程发生在写入前、磁盘失效不在零丢失保证内。

恢复内容包括无标题正文、编码/换行元数据、已命名脏缓冲、工作区根/标签/分栏/位置；不承诺恢复完整 undo 历史。命名文件恢复必须与当前磁盘比对，冲突时保留两者。快照写到用户本地数据目录（便携则其数据目录），不上传；每文档最多保留最近10次冗余快照，30天未认领草稿仅提示清理、不得自动删除唯一未保存副本，总容量预算256 MiB，接近限额提示，绝不为腾空间删除当前未保存的唯一副本；容量不足可阻止热退出。最近列表默认最多50项，可清空/关闭，收藏单独保留并明确说明。没有遥测、云请求、在线字体/高亮依赖；外部链接仅在用户动作后经协议校验打开。

跨文件替换使用不可变预览计划和二次确认；dirty/open buffer、只读文件、磁盘变更、编码不可表示均不可静默跳过。默认排除 dirty 文件，可先保存后重做预览；提交逐文件复核 expectedRevision，保存变更前快照和恢复清单，失败停止并报告已完成/未完成。批次不具备对任意外部进程的全局原子性。回滚也需校验替换后 revision，遇到后续修改保留回滚副本并人工处理，不能覆盖用户新内容。

## 格式化与安全边界

JSON/JSONC、XML、HTML、CSS、JavaScript、TypeScript、SQL、YAML 均有明确 formatter 和失败反馈，见 [search-tools 规格](specs/SPEC-search-tools.md)。JSONC 保留注释；YAML 不做会丢注释/锚点的解析后序列化；SQL 仅声明通用/SQLite、PostgreSQL、MySQL 方言，不保证过程语言。Java 仅语法高亮。格式化是可撤销前端编辑，不自动保存、不执行文档中的代码，不读取工程插件或远程配置。

Markdown 原始 HTML 默认禁用；用户显式启用后仅允许清洗过的受限安全 HTML，去除脚本、事件、iframe、危险 URL；远程图片默认不加载，不能通过预览泄露本地路径或静默网络访问。相对资源仅在文档目录/已授权根内解析，越界需显式授权。HTML 导出是清理过的独立离线文件，资源嵌入受限；PDF 是真实本地 PDF 导出，有可选路径、分页/纸张设置和失败处理，打印对话框中“用户自行选择 PDF”不算实现完成。

## 可测量目标与完成定义

以下是参考目标，非实测结果。参考目标机 Windows 11 x64、4核、8 GiB、SSD，另在 Windows 10 x64 回归；开发机 i5-12600KF/32 GiB/Win11 仅作开发基准，不替代目标机验收。同一版本 WebView2、10次暖测取 p95，冷启动单列。

| 场景 | 目标 |
|---|---|
| 无恢复任务冷启动到可输入 | p95 ≤1.5 s |
| 空闲单窗口 | 主进程+所属 WebView2 合计私有工作集 ≤180 MiB；CPU ≤1%（稳定后30秒均值） |
| 1 MiB 普通文本打开到可编辑 | p95 ≤300 ms（系统缓存暖） |
| 正常文本键入/选择 | 输入到绘制 p95 ≤50 ms，无每键 Rust IPC |
| 100 MiB 以下只读分块首屏 | p95 ≤1 s；不一次展开全部 DOM |
| 1万文件/约100 MiB本地内容目录搜索 | 首批 ≤500 ms，总时长目标 ≤5 s，取消后 ≤250 ms停止投递 |
| 空白安装/便携压缩包 | 应用自身目标 ≤25 MiB，不含系统 WebView2 runtime；独立离线依赖包另计 |

完整 v1 必须通过矩阵全部必需能力、六规格验收、中文/长路径、符号链接循环、编码/换行往返、只读/磁盘满/强制终止/外部并发、恶意 Markdown/SVG、Windows 10/11 x64 安装和便携测试。小地图是唯一明确可选展示项，其开关和不支持提示属于 F-EDIT-012。任何未实现项须明确列出，不可把 MVP 改称完整 v1。
